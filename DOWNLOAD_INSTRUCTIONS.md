# Hotel Management System - Download Instructions

## 📥 How to Download and Run

### Option 1: Portable Version (Recommended)
1. **Download** the `Hotel-Management-System-Portable.zip` file
2. **Extract** the zip file to any location (Desktop, Documents, etc.)
3. **Double-click** `Hotel Management System.exe` to run
4. **No installation required!**

### Option 2: Installer Version
1. **Download** the `Hotel Management System Setup.exe` file
2. **Run** the installer as administrator
3. **Follow** the installation wizard
4. **Launch** from Start Menu or Desktop shortcut

## 🖥️ System Requirements

- **Operating System**: Windows 10 or later
- **RAM**: 4GB minimum (8GB recommended)
- **Storage**: 200MB free space
- **Internet**: Required for online features
- **Permissions**: No admin rights needed for portable version

## 🚀 First Time Setup

1. **Extract/Run** the application
2. **Allow** Windows Defender if prompted (click "More info" → "Run anyway")
3. **Connect** to your hotel management system
4. **Login** with your credentials

## 🆘 Troubleshooting

### Application Won't Start
1. **Check** Windows Defender settings
2. **Run** as administrator if needed
3. **Ensure** internet connection
4. **Restart** your computer

### Slow Performance
1. **Close** other applications
2. **Check** available RAM
3. **Restart** the application
4. **Update** Windows

### Connection Issues
1. **Verify** internet connection
2. **Check** firewall settings
3. **Try** different network
4. **Contact** system administrator
